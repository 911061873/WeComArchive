## 建议里程碑

明确功能范围、需要支持的消息类型、同步时效、数据去向、保留策略、访问控制和合规要求。

实现配置管理、数据同步、消息标准化、存储或转发、重试机制、日志、监控指标和自动化测试。

## 已明确的功能范围

1. 通过独立模块同步客户群列表和客户群详情，获取并保存群成员 ID、名称等基础信息，不与会话存档主类混合。
2. `WeComArchive` 增量拉取企业微信会话存档，解密消息，下载音频、文件等附件并默认持久化。
3. 用户可以在初始化后通过注册方法向 `WeComArchive` 添加消息处理函数。
4. `WeComArchive` 提供长期运行方法，按照初始化时配置的轮询间隔持续拉取新消息。
5. 首版不提供命令行工具；会话存档通过 `WeComArchive` 类使用，客户群同步通过独立模块使用。
6. 初始化主入口类时必须提供企业微信会话存档凭据；数据库和 HTTP 代理配置均可选，未配置数据库时使用 SQLite。
