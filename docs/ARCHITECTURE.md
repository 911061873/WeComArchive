# 系统架构

## 当前状态

架构尚未最终确定。本文档用于记录当前的架构方向，不将待确认问题视为已经完成的决策。

## 候选模块职责

1. 配置与密钥加载
2. 企业微信会话存档 SDK 适配
3. 增量同步与游标管理
4. 消息解密与解析
5. 消息标准化
6. 数据存储或下游投递
7. 重试、幂等与故障恢复
8. 日志、监控指标与审计

## 候选数据流

企业微信会话存档服务 → SDK 适配层 → 解密与解析 → 标准化 → 存储或转发 → 更新同步检查点。

## 设计关注点

- 只有相关数据得到安全处理后，才能推进同步检查点。
- 重复处理不能产生非预期的重复数据。
- 未识别的消息类型应当保留或进入隔离流程，不能被静默丢弃。
- 敏感配置和解密后的会话内容必须得到明确保护。
- SDK 集成边界应隔离原生 SDK 细节与应用业务逻辑。

## 待决定事项

- 数据库或下游系统
- 调度机制
- 附件与媒体文件的存储方式
- 部署拓扑
- 数据保留与删除模型
