# 消息类型需求清单

本文整理原始消息类型需求，不代表所列类型均已实现，也不作为完整支持情况的承诺。
项目范围以 [项目规划](项目规划.md) 为准；当前类型解析能力见
[`src/wecomarchive/parser.py`](../src/wecomarchive/parser.py)。
未知类型仍保存原始加密消息和完整解密数据，只跳过类型分表。

## 需要保存的消息类型

- 文本
- 图片
- 撤回消息
- 同意会话聊天内容
- 语音
- 视频
- 名片
- 位置
- 表情
- 文件
- 链接
- 小程序消息
- 会话记录消息
- 待办消息
- 投票消息
- 填表消息
- 红包消息
- 会议邀请消息
- 会议控制消息
- 在线文档消息
- MarkDown格式消息
- 图文消息
- 日程消息
- 混合消息
- 音频存档消息
- 音频共享文档消息
- 互通红包消息
- 视频号消息
- 音视频通话
- 微盘文件
- 接龙消息
- 笔记消息

## 包含媒体的消息类型

以下为原始需求中列出的媒体相关类型，不等同于解析器的 `MEDIA_TYPES` 集合。
第一版只保存消息数据和已实现的媒体字段，不自动下载附件。

- image
- voice
- video
- emotion
- file
- mixed
- meeting_voice_call
- voip_doc_share
- note
