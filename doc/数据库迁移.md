# 数据库迁移

第二版 schema 初始版本为 `0001_v2`，由 Alembic 管理。空库构造时自动安装最新结构；已有库版本不匹配则抛出错误。
同一数据库只能运行一个主服务实例，执行升级前先停止服务并备份数据库。

```python
from wecomarchive.db import Database
from wecomarchive.migration import upgrade

db = Database("sqlite:///./wecom_archive.db")
try:
    upgrade(db.engine)
finally:
    db.dispose()
```

当前仅保留独立的第二版初始化脚本 `0001_v2_initial.py`，不再提供旧版 `0001` → `0002` 的迁移链或旧数据转换。
新结构直接创建五张业务表：archive_progress、archive_encrypted、archive_decrypted、archive_parsed 和 archive_consumer_task；不创建 archive_type_* 历史类型表。

旧版 `0001`、`0002` 数据库及未受版本管理的已有库均拒绝升级。请先停止服务并备份旧库，再配置一个新的空数据库；SQLite 可使用新的数据库文件路径。初始化不会删除或修改旧库，也不会导入历史数据。

解密状态在 archive_encrypted.status，解析状态在 archive_decrypted.status，消费者状态在 archive_consumer_task.status。
新增类型支持后需要人工将 unsupported 的解析任务改为 pending；failed 不会在重启时自动恢复。
启动会恢复 processing 状态，并恢复已配置密钥版本的 waiting_key 消息。
