MySQL 与 PostgreSQL 使用工作目录内的临时官方便携二进制，仅绑定 127.0.0.1，
使用独立空数据库；测试后关闭，没有安装系统服务。下载来源为
[MySQL 官方下载](https://dev.mysql.com/downloads/mysql/8.4.html?os=3) 与
[EDB PostgreSQL 官方分发页](https://www.enterprisedb.com/download-postgresql-binaries)。

三种后端实际运行同一组事务存储、SDK 替身采集、异步规则消费与生命周期测试，
包括首次游标、续拉、解密失败、未知类型、解析失败、重复消息、插入及提交回滚、
明文与密文留存、Unicode/大 JSON、大小写不同消息 ID、时间窗口开关、队列背压、
消费者异常、多规则独立命中、消息快照隔离、停机超时与重启不恢复。
还验证了外部取消、SDK 阻塞时事件循环可运行、调用结束前不销毁客户端，以及 ORM 与迁移结构一致。

迁移往返和拒绝改写旧库测试使用独立 SQLite 临时文件；三个后端均验证初始迁移、重复初始化和 ORM 结构一致。
SDK 适配测试通过真实 RSA 运算和 SDK 替身验证参数、数据转换与密钥回退。
没有调用真实企业微信接口，也没有向影刀发送请求；这两项需要接入方的实际凭据与接口协议进行联调。

CI 已配置 Python 3.10/3.12 × SQLite/MySQL/PostgreSQL 矩阵；本次没有推送或触发远程 CI，
不把 CI 配置存在视为远程检查已通过。

复现命令见 [README](../README.md#开发与验证)。指定外部测试库时必须使用独立空库。
